# Sistema de inventario para tienda local

Proyecto académico para controlar productos, cantidades y fechas de caducidad de una tienda local.

## Funcionalidad de la versión Beta

- Registro básico de productos.
- Evaluación de fecha de caducidad.
- Semáforo de estado:
  - ROJO: producto caducado.
  - AMARILLO: producto próximo a caducar en siete días o menos.
  - VERDE: producto con más de siete días de vigencia.
- Pruebas unitarias con JUnit 5.
- Integración continua con Travis CI.

## Funcionalidad fuera de alcance en Beta

- Aplicación móvil nativa.
- Lector de códigos de barras.
- Notificaciones por correo o mensajería.
- Integración con sistemas corporativos.
- Almacenamiento de imágenes en la nube.
- Control avanzado de usuarios y permisos.

## Tecnologías

- Java 17
- Maven
- JUnit 5
- GitHub
- Zube
- Travis CI
