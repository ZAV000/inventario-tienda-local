# Manual de usuario

## Ingreso

1. Ejecutar la aplicación.
2. Abrir `http://localhost:8080`.

## Registrar un producto

1. Capturar el nombre.
2. Indicar existencias en piso.
3. Indicar existencias en bodega.
4. Elegir la fecha de caducidad.
5. Presionar **Guardar producto**.

## Interpretar el semáforo

- ROJO: el producto ya caducó.
- AMARILLO: caduca hoy o dentro de siete días.
- VERDE: tiene más de siete días de vigencia.

## Consultar existencias

La tabla muestra cantidades en piso, bodega y total.
