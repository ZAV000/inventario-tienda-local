# Guion breve para el video de demostración

Duración recomendada: 4 a 6 minutos.

1. Presentación del proyecto y problema identificado.
2. Mostrar README, tabla de contenidos y arquitectura.
3. Mostrar issues, etiquetas, branches, commits y pull requests.
4. Ejecutar `java -jar target/inventario-tienda-local-1.0.0.jar`.
5. Abrir `http://localhost:8080`.
6. Mostrar los tres productos de ejemplo.
7. Registrar un producto nuevo.
8. Explicar los estados ROJO, AMARILLO y VERDE.
9. Eliminar un producto como función administrativa.
10. Mostrar el JAR en la release v1.0.0.
